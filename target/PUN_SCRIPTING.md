# Pun Scripting Documentation

Pun is a small PHP-style server-side scripting system that runs inside `.pun` files. A `.pun` file can contain normal HTML plus backend script blocks.

```html
<h1>Hello</h1>

<?pun
naam = "Suneet"
dasso "<p>Sat Sri Akal " + naam + "</p>"
?>
```

The browser receives only rendered HTML. Raw `<?pun ... ?>` source is not sent to the browser.

## File Extension

Pun files use:

```text
.pun
```

Example:

```text
index.pun
form.pun
users.pun
```

## Script Blocks

Pun code must be written inside:

```pun
<?pun
...
?>
```

HTML outside Pun blocks is copied directly to the response.

```html
<h1>Header</h1>

<?pun
dasso "<p>Generated by Pun</p>"
?>

<footer>Footer</footer>
```

Output:

```html
<h1>Header</h1>

<p>Generated by Pun</p>

<footer>Footer</footer>
```

## Keywords

| Keyword | Meaning |
| --- | --- |
| `je` | if |
| `nahi_ta` | else |
| `jad_tak` | while |
| `kaam` | function |
| `wapas` | return |
| `dasso` | print / echo |
| `sach` | true |
| `jhooth` | false |
| `khali` | null |

Reserved for future versions:

```pun
har_ik
vich
nava
jodo
```

## Comments

Single-line comments:

```pun
// eh comment hai
```

Multi-line comments:

```pun
/*
eh multi-line
comment hai
*/
```

## Variables

Variables do not need a declaration keyword.

```pun
naam = "Suneet"
umar = 37
price = 99.95
active = sach
deleted = jhooth
value = khali
```

## Data Types

Pun currently supports:

- number
- string
- boolean
- null

Examples:

```pun
count = 10
price = 99.95
naam = "Suneet"
active = sach
missing = khali
```

## Printing With `dasso`

Use `dasso` to write output into the current page response.

```pun
dasso "Sat Sri Akal"
dasso naam
dasso "Hello " + naam
dasso 10 + 20
```

Inside HTML:

```html
<body>
<?pun
naam = "Suneet"
dasso "<h1>Sat Sri Akal " + naam + "</h1>"
?>
</body>
```

## String Concatenation

Use `+` to join strings.

```pun
naam = "Suneet"
dasso "Hello " + naam
```

String plus number is converted to text reasonably:

```pun
dasso "Total: " + 30
```

Output:

```text
Total: 30
```

## Operator Precedence

Pun follows normal precedence:

```text
assignment
or
and
equality
comparison
term
factor
unary
function call
primary
```

Example:

```pun
natija = 10 + 20 * 2
dasso natija
```

Output:

```text
50
```

## Conditionals

Use `je` for if and `nahi_ta` for else.

```pun
umar = 20

je umar >= 18 {
    dasso "Adult"
}
nahi_ta {
    dasso "Minor"
}
```

Nested conditions work:

```pun
naam = "Suneet"
umar = 37

je naam == "Suneet" {
    je umar >= 18 {
        dasso "Welcome adult Suneet"
    }
}
```

## While Loops

Use `jad_tak`.

```pun
i = 1

jad_tak i <= 5 {
    dasso i
    i = i + 1
}
```

Output:

```text
12345
```

The MVP has loop protection to stop extremely long loops.

## Functions

Use `kaam` to define a function.

Use `wapas` to return a value.

```pun
kaam jod(a, b) {
    wapas a + b
}

natija = jod(10, 20)
dasso natija
```

Output:

```text
30
```

Functions support parameters and local scope.

```pun
kaam sat_sri_akal(banda) {
    wapas "Sat Sri Akal " + banda
}

dasso sat_sri_akal("Suneet")
```

## Scope

All Pun blocks in one `.pun` page share the same page environment.

```html
<?pun
naam = "Suneet"
?>

<h1>Hello</h1>

<?pun
dasso naam
?>
```

Output includes:

```text
Suneet
```

Blocks and functions create child scopes.

```pun
je sach {
    local = 123
}
```

## Request Object: `mang`

Pun exposes the current HTTP request as:

```pun
mang
```

Available properties:

```pun
mang.GET
mang.method
mang.path
```

Read query parameters:

```pun
naam = mang.GET["naam"]
```

Request:

```text
http://localhost:8080/?naam=Suneet
```

Pun:

```pun
naam = mang.GET["naam"]
dasso naam
```

Output:

```text
Suneet
```

If a query parameter does not exist, it returns `khali`.

```pun
naam = mang.GET["naam"]

je naam == khali {
    naam = "Dost"
}

dasso "Sat Sri Akal " + naam
```

URL decoding is supported:

```text
?naam=Suneet%20Kumar
```

becomes:

```text
Suneet Kumar
```

## Response Object: `jawab`

Pun exposes the response object as:

```pun
jawab
```

Available properties:

```pun
jawab.status
jawab.type
```

Defaults:

```text
status = 200
type = text/html; charset=UTF-8
```

Example:

```pun
jawab.status = 200
jawab.type = "text/html"
dasso "<h1>OK</h1>"
```

JSON-style response:

```pun
jawab.type = "application/json"
dasso "{ \"message\": \"Sat Sri Akal\" }"
```

## Property Access

Use dot syntax:

```pun
mang.method
mang.path
jawab.status
jawab.type
```

## Index Access

Use bracket syntax:

```pun
mang.GET["naam"]
```

## Full Page Example

```html
<html>
<head>
    <title>Pun Demo</title>
</head>
<body>

<h1>Pun Language</h1>

<?pun

naam = mang.GET["naam"]

    naam = "Dost"
}

    wapas "Sat Sri Akal " + banda

</body>
</html>
```

Visit:

```text
http://localhost:8080/?naam=Suneet
```

Rendered page includes:

```text
Sat Sri Akal Suneet
10 + 20 = 30
```

## Server Behavior

`GET /` maps to:

```text
index.pun
```

`.pun` files are executed through the Pun template engine.

Static files are served directly:

```text
.html
.css
.js
.json
.png
.jpg
.jpeg
.gif
.svg
.ico
.txt
```

## Error Handling

Syntax or runtime errors return a development error page.

Example:

```text
Pun Script Error
File: index.pun
Line: 12
Message: Variable 'user' does not exist.
```

Java stack traces are not sent to normal browser users.

## Security Model

Pun scripts do not have access to:

- Java reflection
- JVM classes
- `Runtime.exec`
- `ProcessBuilder`
- system commands
- arbitrary filesystem APIs
- `System.exit`
- environment variables by default

Only explicit built-ins like `mang` and `jawab` are exposed.

## Current MVP Limitations

Not implemented yet:

- arrays
- maps
- `har_ik ... vich` loops
- POST data
- cookies
- sessions
- database access
- imports/modules
- package manager
- production server mode
- syntax highlighting
- language server

// loop

    dasso i
    i = i + 1
}

// function
kaam jod(a, b) {

}

dasso jod(10, 20)

// request

// response
